# Hi SQL

[中文](README.zh-TW.md)

## Overview

![](images/orm.png)
![](images/write_sql.png)

Hi SQL is a simple and highly flexible pure __SQL__ library.

### Why choose Hi SQL?
While there are many __ORM Frameworks__ available, you may face the following challenges in different projects:
- Need to learn specific ORM syntax.
- Difficult to ensure that the SQL generated by the ORM meets performance expectations.
- High cost of converting complex or special SQL into ORM syntax.
- High coupling between some ORMs and specific databases.

Hi SQL uses native SQL directly, allowing developers to have full control over query logic while maintaining development efficiency.

## Requirements

* Spring Framework 5+
* Java 11+

## Features

* **Native SQL Focused**: Write SQL directly for maximum control.
* **High Performance**: Extremely lightweight encapsulation to reduce overhead.
* **Parameterization & Dynamic Substitution**: Provides intuitive parameterized queries and syntax substitution.
* **Flexible Object Mapping**: Easily map query results to any Java object.
* **Spring Integration**: Full support for `@Transactional` transaction management.

## Quick Start

### Configuration

By default, it scans all interfaces marked with `@Repository` under the specified package.

[HiSqlConfig.java](src/test/java/pers/clare/hisql/data/HiSqlConfig.java)

```java
@EnableHiSql
public class HiSqlConfig {
}
```

### Create Entity and Interface

* **SQLCrudRepository**

  Inherit `SQLCrudRepository` to get basic CRUD (INSERT, UPDATE, DELETE, SELECT) functionalities for an entity.

  [User.java](src/test/java/pers/clare/hisql/data/entity/User.java) | [UserRepository.java](src/test/java/pers/clare/hisql/data/repository/UserRepository.java)

  ```java
  @Repository
  public interface UserRepository extends SQLCrudRepository<User, Long> {
  }
  ```

* **SQLRepository**

  Inherit `SQLRepository` to create a lighter, more customizable Repository.

### Basic Usage

```java
@Service
public class UserService {
    private final UserRepository userRepository;

    public UserService(UserRepository userRepository) {
        this.userRepository = userRepository;
    }

    public User find(Long id) {
        if (id == null) return null;
        return userRepository.findById(id);
    }
}
```

## Main Features

### 1. Parameterized Queries

* **Standard Parameters**

  ```java
  @Repository
  public interface DemoRepository extends SQLRepository {
      @HiSql("SELECT * FROM test WHERE value = :value")
      List<Object> findAll(String value);
  }
  ```

* **Object Parameters**

  Automatically resolves object properties into parameter names (e.g., `id`, `obj.id`, `name`, `obj.name`). If parameter names conflict, they are overwritten in order.

  ```java
  @Getter
  @Setter
  public class ValueObject {
      private Integer id;
      private String name;
  }

  @Repository
  public interface DemoRepository extends SQLRepository {
      @HiSql("SELECT * FROM test WHERE name = :obj.name LIMIT 1")
      ValueObject findOne(ValueObject obj);

      @HiSql("SELECT * FROM test WHERE name = :name")
      List<ValueObject> findAll(ValueObject obj);
  }
  ```

### 2. Dynamic SQL Substitution

Dynamically add or remove content based on program logic. **Please follow the examples and avoid manual string concatenation to prevent SQL Injection attacks.**

#### Using SqlReplace

```java
@Repository
public interface DemoRepository extends SQLRepository {
    @HiSql("SELECT * FROM test WHERE 1=1 {valueCondition}")
    List<Map<String, Object>> findByString(String valueCondition, String value);
    
    @HiSql("SELECT * FROM test WHERE 1=1 {value}")
    List<Map<String, Object>> findByReplace(SqlReplace<Object> value);
}

@Service
public class DemoService {
    private DemoRepository demoRepository;
      
    public void demo(String value) {
        // Simple string substitution
        demoRepository.findByString("AND column = :value", value);
        
        // Using SqlReplace: Replaces with an empty string if value is null, otherwise substitutes with specified syntax
        demoRepository.findByReplace(SqlReplace.of(value, " AND column = :value"));
    }
}
```

#### Using SqlReplacer (Auto Matching)

Default replacement rules:
- `String`: No replacement if `null` or empty.
- `Collection/Array`: No replacement if empty.
- Other types: No replacement if `null`.

```java
@Repository
public interface DemoRepository extends SQLRepository {
    @HiSql("""
      SELECT * FROM test
      WHERE 1=1
          {value}
          {replace2}
          {value3}
      """)
    List<Map<String, Object>> findAll(SqlReplacer sqlReplacer, DemoQuery query);
}

@Service
public class DemoService {
    private DemoRepository demoRepository;
      
    public void findAll(DemoQuery query) {
        demoRepository.findAll(
            SqlReplacer.create()
                .add("value", " AND column = :value") // When names match
                .add("replace2", "value2", " AND column2 = :value2") // When names do not match
                .add("value3", " AND column3 = :value3", (v) -> v), // Custom judgment logic
            query
        );
    }
}
```

### 3. Read SQL from XML

* **Directory Standard**: Default path is `resources/hisql/`. File names must match the class name.
* **Tag Setting**: Tag names must match method names, or be specified via `@HiSql(name=...)`.

Example: `resources/hisql/CustomRepository.xml`
```xml
<?xml version="1.0" encoding="UTF-8"?>
<!DOCTYPE SQL>
<SQL>
    <findAll><![CDATA[
        SELECT * FROM user WHERE 1=1 {id} AND :id IS NOT NULL
    ]]></findAll>
</SQL>
```

## Advanced Applications

### Pagination Optimization

Avoid repeated `COUNT(*)` execution during page turns by using an initially calculated total.

```java
Pagination pagination = Pagination.of(0, 20);
Page page = repository.page(pagination);

// Submitting the previous total for the next page
pagination = Pagination.of(page.getPage() + 1, page.getSize(), page.getTotal());
repository.page(pagination);
```

### Virtual Total

For large datasets, use the `EXPLAIN` estimated value instead of an exact `COUNT(*)` to significantly improve query performance.

```java
pagination.setVirtualTotal(true);
```

### Cursor Pagination

For sequential data fetching without using traditional offset, you can enable cursor pagination. This overrides the offset to 0 and relies on a cursor condition (e.g., `id > :lastId`) for high-performance iteration.

```java
pagination.setCursor(true);
```

#### MySQL Implementation Example
```java
@Override
public long getVirtualTotal(Pagination pagination, Connection connection, String sql, Object[] parameters) throws SQLException {
    String totalSql = "EXPLAIN SELECT COUNT(*) FROM(" + sql + ")t";
    ResultSet rs = ConnectionUtil.query(connection, totalSql, parameters);
    if (rs.next()) {
        return rs.getLong("rows");
    }
    throw new HiSqlException("Query total error: " + totalSql);
}
```

```java
}
```

```java
}
```

#### Custom Result Set Conversion (ResultSetConverter)
```java
public class CustomResultSetConverter extends ResultSetConverter {
    {
        // Register special type conversion logic, e.g., Pattern
        register(Pattern.class, (rs, i) -> Pattern.compile(rs.getString(i)));
    }
}

@EnableHiSql(resultSetConverter = CustomResultSetConverter.class)
public class HiSqlConfig {
}
```
